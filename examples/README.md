# Sample data

Volumes for trying PrismaMRI without your own imaging. Files in this folder are stored with [Git LFS](https://git-lfs.github.com/) (some exceed GitHub’s 100 MB limit for regular git).

After cloning:

```bash
git lfs install
git lfs pull
```

Load any file from the app import screen (drag-and-drop or **Open file**).
